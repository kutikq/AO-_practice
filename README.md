# Прогнозирование продаж торговой точки

Учебно-практический проект, выполненный в рамках производственной практики в **АО «Центр программ лояльности» (СберСпасибо)**.

---

## Задача

Смоделировать бизнес-показатели розничной точки (бургерная) и построить прогноз на следующие 12 месяцев с сохранением сезонности.

**Исходные условия:**
- 1 торговая точка, 1 000 покупателей, 10 000 транзакций за 12 месяцев
- Формат данных: `shop_id | customer_id | transaction_id | amount | date`
- Прогнозируемые показатели: клиенты в месяц, количество покупок, оборот, средний чек

---

## Методология

### 1. Генерация данных

Датасет строится через **двухслойную мультипликативную модель спроса**, а не рандомом — чтобы воспроизвести реальную структуру торговли.

**Слой 1 — интенсивность трафика:**

```
λ(t) = trend × season_year(t) × season_week(t) × payday(t) × holiday(t) × noise
```

| Компонент | Параметры |
|---|---|
| Годовая сезонность | Пик декабрь (×1.40), тrough лето (×0.75); амплитуда пик/провал **1.6×** |
| Недельная сезонность | Пт/Сб +30–40%, Пн −20%; нормировка `/mean()` |
| Зарплатные дни | Всплеск ~10-е и 25-е числа каждого месяца |
| Тренд | +7%/год (откалиброван по данным Росстат по отрасли) |
| Сглаживание | `rolling(21)` для устранения артефактов на стыках месяцев |

**Слой 2 — клиентская база (NBD-модель):**

Каждому клиенту назначается личная интенсивность λᵢ ~ Gamma(0.5, 1.0) с clip(0.05, 3.5) — это воспроизводит **Парето-распределение активности**: топ-20% клиентов формируют ~60–70% покупок. Верифицировано через кривую Лоренца.

Средний чек: логнормальное распределение (σ = 0.30/0.22), база 500 руб., seed=7.

### 2. Агрегация

Транзакции агрегируются на **недельный уровень** (52 точки вместо 12 месячных) — это позволяет модели надёжно оценить сезонность, не переобучаясь.

### 3. Прогноз — SARIMAX

Модель `SARIMAX(1, 0, 0)` из `statsmodels` с экзогенными признаками:

- Фурье-гармоники (K=2) для годовой сезонности
- Линейный тренд
- Ряд прогнозируется в лог-масштабе (мультипликативность → аддитивность)

Четыре независимые модели: **клиенты / покупки / оборот / средний чек**.

**Три сценария** роста трафика: 0% / +7% / +15%.

## Технологии

| Библиотека | Применение |
|---|---|
| `numpy` | Генерация стохастических распределений (Gamma, Lognormal, Poisson) |

## Результаты

Модель валидировалась на **скрытом «году 2»**, который не участвовал в обучении:

| Показатель | MAPE | MAE |
|---|---|---|
| Клиенты | 8.1% | 12.9 |
| Покупки | 9.9% | 20.7 |
| Оборот | 10.3% | 13 287 ₽ |
| Средний чек | 2.7% | 16.7 ₽ |

**Модель по обороту превзошла наивный прогноз (повтор года 1):** MAPE 10.3% vs 11.2%.
